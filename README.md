# Job Market Intelligence

Web scraping and data analysis project focused on the labor market.

## Objective

Build a system capable of collecting, cleaning and analyzing job offers to identify:

- Most requested skills
- Technologies
- Job roles
- Salary ranges
- Work modalities
- Experience requirements
- Trends in the data job market

## Technologies

- Python
- Web Scraping
- Pandas
- SQL
- Excel
- Power BI
- Git/GitHub
